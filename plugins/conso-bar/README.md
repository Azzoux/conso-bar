# conso-bar

Une barre fine au-dessus de la zone de saisie de Claude Code, inspirée d'Apple Screen Time.

- **Consommation** : % utilisé sur 5 h et 7 j, avec un point vert / orange / rouge selon le rythme.
- **Travail** : barre violette animée pendant les réponses (dégradé, reflet, pulse), % qui suit la liste de tâches, couleur selon l'action, ✓ vert menthe à la fin.

## Installation

Dans Claude Code :

```
/plugin marketplace add <owner>/conso-bar
/plugin install conso-bar@conso-bar
```

La barre complète s'affiche dans le terminal et l'app desktop ; sur web et mobile, les % apparaissent dans la ligne d'état.
